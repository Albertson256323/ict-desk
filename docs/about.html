What this is

A paper-trading simulation — it tracks hypothetical trades based on real market data, but never places live orders or touches real funds. Everything here is for tracking whether the strategy's logic actually works over time.

Entry conditions

A symbol is scanned every cycle and a trade is only opened when all of the following line up on the 15-minute chart:

  • Displacement — the latest candle's body is at least 2.2× the 10-candle average body size, signalling an unusually strong directional move.
  • Fair value gap (FVG) — a price gap forms between that displacement candle and two candles prior, leaving an untraded zone.
  • H4 bias — the most recent 4-hour candle must be bullish, used as a higher-timeframe confirmation filter.

Entry, stop, and target

  • Entry — the midpoint of the fair value gap.
  • Stop-loss — the lowest low of the four candles immediately before the signal candle, a real recent structural level.
  • Take-profit — the most recent swing high in the lookback window, an actual liquidity level rather than an arbitrary multiple.
  • Minimum reward-to-risk — the setup is only taken if that swing-high target offers at least 1:3 reward relative to the stop distance. If the real structure doesn't offer at least that, the setup is skipped.

There's no fixed position sizing or dollar-risk tracking — this tracks price levels only, not account balance.

How it runs

A scheduled job checks the market roughly every 15 minutes: it scans for new setups, checks any open position against its stop-loss and take-profit, logs the result, and rewrites this site. No server runs continuously — each check is a single pass that starts, does its work, and exits.

This page is static and only updates when manually edited.
